## BUSINESS INFORMATION

* Women's Ethnic Wear
* Sarees

Orders: **Online orders accepted**

# 1. OVERALL DESIGN

Create a luxurious, elegant Indian fashion aesthetic.

Color palette:

* Warm ivory / cream background
* Burgundy / wine red as the primary brand color
* Soft blush pink accents
* Gold accents for premium details
* Dark charcoal text

The design should be inspired by the uploaded HAIRA logo:

* Elegant
* Feminine
* Minimal
* Premium
* Traditional Indian influence with a modern layout

Do NOT make the website look overly colorful or like a cheap marketplace.

Use:

* Large high-quality fashion imagery
* Elegant serif headings
* Clean modern sans-serif body text
* Generous whitespace
* Subtle animations
* Soft hover effects
* Rounded cards where appropriate
* Premium product presentation

Make the website look excellent on both desktop and mobile.
